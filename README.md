# Susheemk Portfolio Blog
https://susheemk.github.io

This is a personal technical blog/portfolio hosted on GitHub Pages. It documents my work in software development, research, writing, and presentations.

## Key Sections
- **Home**: `index.html`
- **Building Experiments**: `building.html` (code experiments, projects)
- **Reading Articles/Papers**: `reading.html`, `reading-articles.html`, `reading-papers.html`
- **Writing Notes/Papers**: `writing.html`, `writing-notes.html`, `writing-papers.html`
- **Talks**: `talks.html`

## Structure
- `assets/`: Static assets (images, stylesheets)
- `.git/`: Git repository metadata
- `.claude/`: Empty directory (likely unused)

## Contribution
This is a static site; no server-side logic is involved. You can:
1. Fork the repo and modify HTML/CSS directly.
2. Add new pages by creating HTML files in the root.
3. Update assets in the `assets/` folder.

For questions, contact [Susheem K](https://susheemk.github.io).
